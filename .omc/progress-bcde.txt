### Learnings
- asyncio.Task.cancel() transitions to "cancelling" not "done" until the
  event loop processes the cancellation — tests must await the task before
  asserting .done()/.cancelled().
- _setup_logging re-runs on every _cmd_start call; must strip prior
  RotatingFileHandler+StreamHandler from root to avoid duplicate handlers.
- edge-tts NoAudioReceived lives at edge_tts.exceptions.NoAudioReceived, not
  at module top level — use the fully qualified path to avoid AttributeError
  on import order.
- Pipecat 0.0.108 GroqSTTService emits TranscriptionFrame BEFORE SmartTurn
  emits UserStoppedSpeakingFrame. Our _extract_transcript only needs to match
  TranscriptionFrame; the UserStoppedSpeakingFrame branch (removed in
  phase A deslop) was dead code.
