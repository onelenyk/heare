# Owner Auto-Enrollment — Progress Log

## Session: 2026-04-24

### Task
Implement automatic owner enrollment to eliminate manual CLI setup requirement.

### Design Decisions
- Threshold: 5 turns (higher than guest's 2) for safety
- Owner enrollment checked BEFORE guest enrollment in _maybe_auto_enroll()
- Reuses existing _stranger_candidates deque (no new state)
- TTS notification: "Тепер я впізнаю твій голос." (Ukrainian)
- Safety: never overwrites existing owner entry
- KEY DESIGN POINT discovered during impl: when owner-enroll is enabled and
  no owner exists, the guest path is fully suppressed — otherwise the lower
  guest threshold (default 2) would always fire first and the owner slot
  would never accumulate to 5. After owner is enrolled (or owner-enroll
  is disabled), guest path runs normally.
- TTS push happens via loop.create_task() so push_frame's await does not
  re-enter the tagger; failure is caught and logged.
