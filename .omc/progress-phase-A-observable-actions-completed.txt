## Learnings / patterns

1. claude-agent-sdk separates tool output from assistant text: bash stdout lives in UserMessage → ToolResultBlock, not AssistantMessage → TextBlock. Anything that needs to see tool output must iterate UserMessage too.
2. ToolResultBlock.content has three legal shapes (str / list[dict] / None). A dict item's text key is the canonical place; unknown shapes should be repr'd, not dropped.
3. The generator's _scrub_tts_text is a module-level helper suitable for reuse from main.py's action callbacks — same defense-in-depth against tool-name leaks.
4. Ordering fix in main.py: any code that pushes frames through `processor` must run AFTER build_pipeline. The old ordering worked only because the old callbacks never touched processor.

## How to live-verify
1. `uv run python -m src.main start`
2. Say: "запусти echo hello"
3. Expected daemon.log entries:
   - [INTENT SUBMITTED id=N tool=bash]
   - [ACTION RESULT id=N] summary=...hello
   - [ACTION SPEAK id=N len=...]
4. Expected audio:
   - Generator's streamed reply ("зараз виконаю" or similar)
   - After action completes: TTS speaks the summary (or "Готово." if empty)
5. To test error path: "запусти sleep 1000" (action_timeout defaults to 120s). Wait out the timeout and listen for "Дія не встигла, скасовую."
