## Learnings

1. ClaudeSDKClient must not be shared across concurrent callers. An asyncio
   Lock around the full query+receive_response flow is the minimum viable
   guard; splitting into two dedicated clients is still Phase D future work.
2. The AssistantMessage.TextBlock summary from Claude usually already echoes
   the key bash stdout, so always appending the raw ToolResultBlock was double
   talk. Prefer-text, fallback-to-tool_result is the right default.
3. Claude Code's bash tool emits literal status markers ('(Bash completed with
   no output)') as ToolResultBlock content. These are invisible to the user
   but leak to TTS unless scrubbed as a whole phrase.
4. The summarization prompt MUST name the target language explicitly. Saying
   only "reply with ONE line" yields English because Claude defaults to the
   language of the prompt itself.
