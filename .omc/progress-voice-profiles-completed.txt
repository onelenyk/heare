# Voice profile management tools — Progress Log

## Session: 2026-04-25 (Ralph)

### Status
COMPLETE. 852 pytest tests pass; ruff clean on all changed Python files (E402 in src/direct_tools.py:23 is pre-existing, documented out of scope).

### Feature
Added full agent control over voice profiles with 4 new direct tools: list_profiles, create_profile, rename_profile, delete_profile. The agent can now show all profiles in a plain text table, create placeholder guest profiles, rename profiles, and delete non-owner profiles. Audio feedback (success/info beeps) is provided for all operations via new IndicationKind entries.

### Files changed
- `src/indication.py` — added 3 new IndicationKind entries (PROFILE_CREATED, PROFILE_RENAMED, PROFILE_DELETED) with level mappings and default messages
- `src/tool_registry.py` — added 4 new Tool entries to TOOLS dict (list_profiles, create_profile, rename_profile, delete_profile)
- `src/direct_tools.py` — added routing in execute_direct() and implemented 4 handler functions:
  - `_execute_list_profiles()` — builds plain text table with ID, Label, Refs, Created columns
  - `_execute_create_profile()` — creates placeholder guest_NN with empty embeddings list, max 99 guests enforced
  - `_execute_rename_profile()` — parses "id new_label" args, calls gallery.rename_speaker()
  - `_execute_delete_profile()` — prevents owner deletion, calls gallery.remove_speaker()
- `prompts/generator.txt` — added tool descriptions and 4 usage examples in Ukrainian

### Design decisions
1. **Plain text table output** — Used ASCII table format instead of Rich console since agent responses are spoken/text. Format: "ID       | Label      | Refs | Created" with separator line.
2. **Placeholder profiles** — create_profile makes entries with empty embeddings list that auto-enroll can fill later. No voice recording required (per user choice).
3. **Owner protection** — delete_profile explicitly blocks deletion of "owner" profile with error message.
4. **Guest numbering** — Auto-increments guest_NN suffix by finding max existing N and using N+1.
5. **Audio feedback** — PROFILE_CREATED/RENAMED use SUCCESS level (success beep), PROFILE_DELETED uses INFO level (info beep).

### Out of scope
- Voice recording during create_profile — user opted for placeholder creation
- Bulk operations (delete all, rename all) — single-profile operations only

### Learnings
1. **Type hint syntax** — Must be `"Settings | None" = None` not `"Settings | None = None)"` — the `= None` default value is outside the type hint string.
2. **Plain text tables** — ASCII format with fixed-width columns works well for voice agent output; Rich console would be overkill.
3. **Guest numbering** — Finding next available slot requires scanning existing guest_NN IDs, not just counting.

2. 2-turn hysteresis: active_lang switches only after 2 consecutive non-current detections.
3. Single English prompt with {user_language} placeholder (best LLM instruction-following).
4. Static 3-entry voice map: en→en-US-AriaNeural, uk→uk-UA-OstapNeural, ru→ru-RU-DmitryNeural.
5. [LANG_MISMATCH] WARNING logging (Cyrillic/Latin script ratio heuristic) for observability only — no retry.
6. Confirmation phrases kept Ukrainian-only (actively used by decider.py) — deferred to PRD C.
