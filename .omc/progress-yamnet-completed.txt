## Async pattern (per Architect/Critic consensus)
- process_frame uses asyncio.create_task(asyncio.to_thread(self._infer, ...)) + task.add_done_callback(self._on_result)
- _on_result(fut) reads fut.result() inside try/except and resets _running in finally — exception cannot deadlock the observer.

## Drop policy
- _running flag guards inference scheduling. While inference is in flight, fully-buffered windows are discarded (del _buf[:WINDOW_BYTES]). No queueing.

## Confirmation rule
- Two consecutive 0.96 s windows must agree on the same allowlisted label above threshold (default 0.4) before write_audio_event is called.

## Failure modes (all return None from factory + log WARNING)
- Feature flag off (silent no-op)
- onnxruntime not installed (logs "onnxruntime not installed — install heare[audio-event]")
- Model file missing at settings.yamnet_model_path (logs path + tf2onnx hint)
- Inference exception inside _infer (logged, _running resets via finally, _prev_label resets)
