### Learnings:
- TurnAggregator works independently of Pipecat pipeline (adapter pattern)
- Mode-aware timeouts critical for UX (0.5s vs 3.0s)
- Safety limits prevent pathological cases
- Feature flags enable gradual rollout and safety
- Database schema design affects query performance (indexes added)
- Mock patching requires careful path specification
- Conversation context must be optional (backward compatibility)
- Claude API calls need proper error handling and timeouts
