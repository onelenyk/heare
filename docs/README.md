## Як писати, щоб не повторилось

- **Кожне твердження з коду, а не з попереднього документа.** Архів як
  джерело фактів не цитувати.
- **Дата вгорі кожного файлу**, і одна фраза «звірено з кодом такого-то
  числа».
- **Що можна згенерувати — генерувати.** `make stend` і `make doctor`
  вже читають код; документ, який дублює їх, застаріє першим.
- **Нічого не описувати двічі.** Один факт живе в одному файлі.
- **Коротко.** Довгий документ ніхто не звірить, тож він гниє.
