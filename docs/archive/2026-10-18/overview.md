# heare: що це і що воно вміє

2026-09-18. Звірено з кодом 2026-09-18 (гілка `refactor/design-v2`).

heare — голосовий асистент для macOS. Один процес: слухає мікрофон
постійно, відповідає, коли до нього звернулись, може щось зробити руками
(шел, файли, веб, браузер, MCP) і час від часу озивається сам. Двигун —
`src/spine/`, без фреймворків. Дашборд на `http://127.0.0.1:9780`
обслуговує той самий процес (`src/main.py:168`).

Живий стан — не тут. `make doctor` збирає двигун без мікрофона і питає
об'єкти, а не конфіг (`src/doctor.py`). Цей файл каже, що кожне вміння
**є**, від чого воно **залежить** і чи воно **є сьогодні**; як воно
влаштоване всередині — `architecture.md`; що зламано — `known-issues.md`.

## Перемикачі

Усе необов'язкове має ім'я в `src/spine/features.py:48-76`; «off» означає
«не збудовано», а не «попрошено мовчати». Джерела, від найгучнішого:
`HEARE_WITHOUT=roles,mcp`, `HEARE_SAFE_MODE=1`, `--without`,
`spine_features = { roles = false }` у `config.toml`, типове значення
(`features.py:22-27`). Перемикач на дашборді пише в `config.toml` і просить
рестарту (`src/api.py:1214`). Колонка «сьогодні» — з `make doctor` 18.09.

| Фіча | Типово | Що втрачаєш, якщо off | Сьогодні |
|---|---|---|---|
| aec | on | мікрофон глухне, поки асистент говорить | `?` — потребує мікрофона |
| wake | on | реагує на будь-яку мову в кімнаті | on |
| tools | on | тільки розмовляє | on |
| roles | on | мітинг, вчитель, інтерв'ю, суфлер | on |
| mcp | on | зовнішні MCP-сервери | `?` — будує демон, після `npx` |
| memory | on | нічого не пам'ятає між розмовами | on |
| persist | on | розмови не пишуться в базу | on |
| usage | on | витрати не рахуються | ok (єдиний плагін, `src/features/usage`) |
| telemetry | on | немає `turns.jsonl` | `?` — будує демон |
| engine | on | не озветься сам, не пам'ятає, що винен відповідь | on |
| watcher | **off** | не бачить, чим ти зайнятий | on (увімкнено в конфігу) |
| hear_all | **off** | не пам'ятає сказаного не до нього | OFF |
| repeats | **off** | не помічає, що ти вкотре кажеш «треба» | on (увімкнено в конфігу) |

## Голосовий тракт

Це не фічі — без цього асистента нема (`features.py:45-47`).

- **Слух.** Енергетичний VAD (`src/spine/vad.py`), один годинник закриває
  хід, коли скінчились слова, а не час (`src/spine/turn.py`; 1.3 с,
  `config.py` `spine_turn_hold_seconds`). Розпізнає Groq Whisper
  (`src/spine/stt.py`), підказка мови `groq_language = "uk"`. Галюцинації
  Whisper відсіює фільтр (`src/spine/main.py:141`). **Потребує GROQ_API_KEY**;
  без нього демон чекає ключа. Сьогодні: працює.
- **Ім'я (wake).** Чує все, але до моделі доходить лише те, що після
  імені; вікно 45 с росте до 180 с з кожним прийнятим ходом і
  оновлюється тільки прийнятими ходами, не шумом (`src/spine/wake.py`
  `WakeGate`, `main.py:451-457`). Ім'я — з `identity.json`
  (`src/spine/wake_phrases.py` `own_name`). Працює.
- **Голос.** Edge TTS через ffmpeg, без ключа (`src/spine/tts.py`); голос
  обирається за абеткою відповіді — кирилиця на англійському голосі це
  тиша (`src/spine/voicing.py` `pick_voice`). Потребує `ffmpeg` у системі.
  Працює.
- **Перебивання.** Двоступеневе: голос над динаміком паузить його
  одразу, вердикт «перебив / кивнув / скасував» — за тривалістю й
  текстом (`src/spine/loop.py:151-156`, `:295-360`). Деталі —
  `architecture.md`. Працює.
- **Ехо (aec).** WebRTC AEC3 (`src/spine/aec.py`, `main.py:185-194`); без
  нього напівдуплекс. Збирається лише з живим мікрофоном.
- **Чи ще чує.** Пристрій 20 с мовчить і ніхто не мутив — скаже вголос
  раз і спробує відкрити мікрофон знову (`src/spine/hearing.py`,
  `main.py:512-530`). Працює.

## Інструменти: голосу прямо і доручені

Розділ часовий, не інтелектуальний (`src/agent/tools/system.py:45-53`):
голосова модель має відповісти за секунду, тому бачить лише дев'ять схем
(`src/spine/tools.py:408-637`, `SCHEMAS`). Усе важче йде через `delegate`
до воркера **Hands** (`src/agent/hands.py`) без дедлайну; відповідь
повертається в розмову пізніше, власним повідомленням.

**Голосу прямо** (виконує `VoiceToolbox.execute`, `tools.py:701-726`):

| Дієслово | Що робить | Залежить від | Сьогодні |
|---|---|---|---|
| delegate | віддає задачу воркеру | tools | працює |
| remind | нагадати за N хвилин, коли людина тут і тиха | engine (`main.py:426-434`) | працює |
| remember / recall | записник фактів у `memories` | memory | працює |
| forget | стерти **підслухане** за N хвилин, не розмови | persist, hear_all | працює (нема чого стирати, поки hear_all off) |
| search_conversations | «що я казав про…» — пошук по транскриптах, з датою | persist (`src/spine/search.py`) | працює |
| read_display / clear_display | прочитати чи витерти панель на дашборді | persist | працює |
| look_at_screen | знімок усього екрана → модель зору, ~2 с, файл стирається | ключ провайдера зору (openrouter, `config.py:321-322`) + дозвіл «Запис екрана» | працює (ключ є) |

Доктор рахує «голосу прямо 8», бо `search_conversations` є в `SCHEMAS`,
але не в `TOOLS` (`system.py:72-84` vs `:142-728`); модель бачить дев'ять.

**Доручається** (Hands, `hands.py` `_tool_schemas`): усі увімкнені з
`TOOLS`, крім `delegate`, крім заборонених активною роллю і крім тих, що
нічим виконати (`hands.py:69` `unreachable_tools`). Групи:

| Група | Інструменти | Залежить від | Сьогодні |
|---|---|---|---|
| Шел і файли | bash, read, write, create/extract_archive, batch_operation | `~/.heare/workspace` | працює |
| Веб | web_fetch, web_search | Serper, інакше DuckDuckGo (`direct.py:579-608`) | **без SERPER_API_KEY** — DDG, який блокує на хвилини |
| Екран | show_text, show_canvas, read_display, clear_display, look_at_screen | таблиця `displays`; зір як вище | працює |
| Пам'ять | remember, recall, forget (тут — за id!), memory_status | memory | працює |
| Скіли | list_skills, run_skill | `~/.heare/skills`, `skills/` у репо | працює; три вшиті скіли (`skills/`) |
| Демон і звук | stop/restart_daemon (з підтвердженням), mute_bot, mute_mic, mic_gain, volume, audio_input/output, set_provider | HTTP API демона | оголошено; не звірено вухом |
| Профіль | add/list_favorites, set_view_preference, show_profile | — | працює |
| Браузер | 8 дієслів, `hands.py:62-67` | див. нижче | сховано, поки Chrome не спарено |
| workflow | — | — | **вимкнено**: за ним нічого немає (`system.py:573-579`) |
| mcp__* | усе, що дали сервери | див. нижче | по факту підключення |

Роль з `deny_tools` — це справжні ґрати у воркері, не порада в промпті
(`main.py:363-387`, `tools.py:146-153`).

## Браузер

Демон піднімає WebSocket-міст на `127.0.0.1:9333` з токеном
(`src/agent/browser_bridge.py`, `spine_engine.py:961-1030`,
`config.py:381-383`). Поки розширення Chrome не спарене, вісім дієслів
воркеру не пропонуються (`hands.py:69-87`) і з'являються без рестарту,
щойно спарується; вимкнути й змінити токен — з дашборда, теж без рестарту.
Сьогодні: міст будується; чи спарено Chrome, каже значок на дашборді.

## MCP

`~/.heare/mcp/.mcp.json`. Сервери підключає демон після старту (холодний
`npx` може йти хвилину) і перечитує файл без рестарту
(`spine_engine.py:915-960`, `reload_mcp` `:611`). Інструменти отримує
воркер, не голос (`tools.py:85` `McpHands`); голосу вони — привід доручити
(`main.py:588-601`). Що саме підключилось — картка на дашборді, не доктор.

## Пам'ять і записи

- **Записник** (`memories`; `main.py:196-199`): що попросили запам'ятати;
  три найближчі факти йдуть у промпт (`main.py:565-577`).
- **Транскрипти** (`src/spine/persist.py`): кожен хід і відповідь з межами
  розмов; чотири останні обміни йдуть у промпт; тут шукає
  `search_conversations`.
- **Підсумки розмов** (`src/spine/summary.py`, `engine.py:396-427`): коли
  розмова закінчилась тишею — дві речення від моделі; короткі не пишуться.
- **Підслухане** — лише з `hear_all` (`loop.py:467-480`); стирається
  голосом через `forget`. Сьогодні off.
- **Витрати** (`src/features/usage`): леджер оплачених викликів; реальну
  ціну каже лише OpenRouter (`llm.py:73-78`).
- **Телеметрія** (`src/spine/telemetry.py`): рядок на хід у
  `~/.heare/logs/turns.jsonl`; `make day` читає базу й показує день.

## Ролі

Markdown у `roles/` і `~/.heare/roles/` (`main.py:342-345`): вмикаються
фразою, закінчуються фразою, наприкінці — артефакт у
`~/.heare/workspace/artifacts/` і коротке усне резюме (`src/spine/roles.py`,
`role_flow.py`). Канали: `voice` — розмовляє; `log` — мовчить до кінця,
пише; `hints` — мовчить, а підказки їдуть на дашборд (`role_flow.py:173-180`,
`spine_engine.py:1259`).

| Роль | Тригер | Канал | Заборонено |
|---|---|---|---|
| мітинг | «почни мітинг» | log | bash, write, stop/restart_daemon, mcp__* |
| вчитель | «повчи мене» | voice | — |
| інтерв'ю | «потренуй співбесіду» | voice | — |
| суфлер | «режим суфлер» | hints | — |

Сьогодні: чотири ролі завантажуються; працює.

## Ініціатива

Двигун (`src/spine/engine.py`) тримає **наміри** — що асистент хоче
сказати і ще не сказав (`src/spine/intents.py`, рядки в базі, переживають
рестарт). Тригер — не таймер (`repeats.py:1-12`), а подія: закінчилась
розмова, завершилась робота, настало нагадування, зник мікрофон. Коли
можна — умови в коді, не в промпті: не серед ходу, не в порожню кімнату,
не вночі 22:00–07:00 (`situation.py:31-32`), не надто часто
(`engine.py:183-186`). Модель питають одне: чи варто і як
(`main.py:229-321`). Довіра — множник тиші: відмахнулись — мовчить довше
(`engine.py:744-748`). Джерела приводів:

- **watcher** — який застосунок попереду, як давно торкались клавіатури,
  чи змінився буфер обміну (не зміст) (`src/spine/environment.py`);
- **repeats** — «втретє за два дні чую: треба оновити сертифікат» — три
  згадки, два різні дні, про себе (`src/spine/repeats.py`).

Деталі — `initiative.md`. Сьогодні: engine, watcher, repeats збудовані.

## Дашборд

`src/frontend/` через `src/api.py` (маршрути `api.py:222-274`), опитує
`/state`, `/activity`, `/display` щосекунди. Звідти: ключі, провайдер і
модель (без рестарту — `main.py:45-66` `_live_cfg`), перебивання, mute,
текстовий хід (`loop.inject`), панель екрана, пам'ять, наміри, картка фіч
з живого демона (`spine_engine.py:440-451`), міст. Деталі — `dashboard.md`.

## Ключі й провайдери

Сховище — macOS Keychain, сервіс `heare`; змінна оточення перемагає,
`~/.heare/.env` лише там, де Keychain нема (`src/keys.py:1-27`). Розмова й
воркер — один провайдер, `llm_provider` з `deepseek | zai | opencode |
openrouter` (`config.py:303-326`, `providers.py:42-135`); обраний без ключа
гучно підміняється на той, що має (`llm.py:33-70`). Зір — окремо
(`vision_provider`, типово openrouter), бо DeepSeek картинок не бере.

| Ключ | Для чого | Сьогодні |
|---|---|---|
| GROQ_API_KEY | слух | є |
| DEEPSEEK_API_KEY | розмова і воркер (типовий) | є |
| OPENROUTER_API_KEY | розмова/воркер за вибором, зір, чесна ціна | є |
| ZAI_API_KEY, OPENCODE_API_KEY | альтернативні провайдери | не задано |
| SERPER_API_KEY | пошук у вебі замість DDG | не задано |

## Як запустити й перевірити

```
make dev               # демон на передньому плані (uv run python -m src.main start)
make start|stop|status # те саме у фоні через ./hearectl; make logs, make restart, make launch
make doctor            # що збудувалось насправді, без мікрофона
make day [DAYS=3]      # що сталося сьогодні: розмови, незапитане, ціна, швидкість
make stend             # docs/stend.html, прочитаний з коду
make test              # pytest -q, разом з tests/e2e (зібраний застосунок на фейках)
make test-full         # те саме, -v
make spine-acceptance  # живі Groq/DeepSeek/Edge, ~15 хв і соак — коштує грошей
make menubar           # меню-бар macOS; make build / make dmg — Heare.app
```

`make quickstart` теж є, але шукає `.env` у теці репо — з 13.09 ключі в
Keychain, тож він застарів. Спершу: `uv sync`, `brew install portaudio ffmpeg`,
дозволи на мікрофон і (для `look_at_screen`) запис екрана.
