KEY LEARNINGS / CAVEATS
- TurnAggregator is LEGACY and NOT wired into the native Pipecat pipeline
  (build.py has no TurnAggregator reference; native turn-finalisation is
  smart_turn + transcription_gate debounce). The profile.turn_timeout
  wire-in is structurally correct and forward-compatible but does NOT
  change live native-pipeline turn timing today. Likewise the
  session_state flush hook has no native turn-flush target yet, so
  set_mode's flush_pending() is a safe no-op in the live pipeline.
  Both are documented follow-ups, surfaced not hidden.
- Phase 0 spike (LLMUpdateSettingsFrame schema-strip) and Phase 4b are
  intentionally OUT OF SCOPE per the approved ADR. Execution-time deny
  ships independently; denied tools remain visible in the schema (mitigated
  by the mode prompt_addendum naming the restriction).
- indication tests pass Mode enum to mode_provider; _mode_allows_sound was
  made polymorphic (Mode/str/ModeProfile) to preserve that contract.
