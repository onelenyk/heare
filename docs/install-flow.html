Одна команда → одна локальна форма → все налаштовано.

Це пропозиція, а не поточний стан: у коді цього ще немає.

Підписаний .pkg — це та сама начинка (ядро, колеса, інсталятор), лише в обгортці. Робимо його тоді, коли треба віддавати людям, а не собі.

4 · Що це міняє

  • Сайт — замість генератора команд: одна кнопка, команда завжди та сама. Вибір частин переїхав у форму.
  • Інсталятор — ставить лише ядро й наглядач. Частини ставить форма, коли їх обрали.
  • Наглядач — додає локальну форму. Вона існує тільки тоді, коли потрібна: перший запуск або збій.
  • Конфіг — пише форма: адреса й ключ, один раз на машину. Частини читають його при старті.
  • Браузер — без інсталяції: відкрив домен, ввів код. Кожне вікно — своя частина.

5 · Порядок

01
Авторизація
сесії, одноразові коди, сторінка без майстра. Без неї «ввести домен» означає «зайди хто хоче».
02
Форма + одна команда
наглядач відкриває форму; сайт перестає генерувати прапорці.
03
Тунель + домен
https, Cloudflare, мозок ззовні.
04
Пуш + тег
реліз із колесами, після чого команда справді працює.
05
Підписаний .pkg
коли треба віддавати іншим. Начинка не змінюється.
