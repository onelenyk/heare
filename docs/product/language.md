# Мова: контекст англійською, люди — своєю

Почато 27.10.2026. Продовжує `voice-context.md`.

## Правило

| Що | Мова |
|---|---|
| Усе, що читає модель: промпти, блоки контексту, описи частин і вмінь, стани, відповіді інструментів, записи системи | **англійська** |
| Дані людини: розмова, факти, канвас, назви, міста | **як є** — будь-якою мовою, ніхто не перекладає |
| Розуміння мови людини: «вчора», «стоп», фрази пробудження, галюцинації розпізнавача, стоп-слова пошуку | **словник на мову** (`uk.py`, далі `en.py`), не переклад |
| Що людина чує й бачить: сказане вголос, сторінка, мітки частин, CLI, майстер, застосунок Mac | **локалізація**: `uk`, `en`; типово `uk` |

Англійська — основа: ключ перекладу — сам англійський текст, бракує
перекладу — видно англійську, нічого не ламається.

## Інструменти

- **Python — `gettext`** (stdlib; ядру можна). `_("Microphone")`;
  каталоги `locale/<lang>/LC_MESSAGES/heare.po` в одному місці.
- **Babel** — лише розробка: `pybabel extract / update / compile`.
  `make i18n` оновлює й компілює; `make i18n-check` у `make check` — падає,
  коли рядок без перекладу `uk`.
- **Сторінка** — той самий `.po` → JSON, `/api/i18n/<lang>`, у сторінці
  `t()`. Одне джерело перекладів.
- **Мітки частин** — частина шле англійську мітку; сторінка перекладає
  через каталог, незнайоме показує як є. Частина досі сама власник своїх
  налаштувань.
- **Застосунок Mac** — String Catalog (`.xcstrings`).
- **Вибір** — налаштування `language` (`uk`|`en`), перемикач на сторінці;
  сказане вголос — тією ж мовою.

## Етапи

Кожен — окремий комміт, `make check`, `make live`, перевірка вухом/очима.

### 1. Контекст англійською
Промпти й записи, які читає модель, поза голосом (голос зроблено в
`voice-context.md`):
- суддя `model/judge.py`, доручення `model/delegate.py`, `mind.py`,
  `features.py` (що з них читає модель);
- пам'ять: `memory/consolidate.py` (вилучення фактів) — нові факти
  пишуться англійською; старі лишаються;
- руки: `cli_hands.py`, `reach/agents.py`, `reach/acp.py`, `reach/terminal.py`
  (що з них іде агенту);
- відповіді інструментів, які читає модель, а не людина (`read_only`).

Не чіпаємо: сказане вголос (етап 2), словники мови (група 3), JUDGE-приклади
фраз людини — це цитати людини, дані.

Перевірка: `make prompt`; вухом — суддя відповідає/мовчить як раніше,
нагадування, доручення, «що ти пам'ятаєш про мене».

### 2. Каркас локалізації
`heare-core/heare/i18n.py` (`_`, `language()`), каталог `uk`, Babel у dev,
`make i18n`, `make i18n-check`, налаштування `language`. Перший споживач —
сказане вголос: «Беру.», «Зупинив.», нагадування, рядок невдачі.

### 3. Сторінка й мітки частин
`page.html` → `t()` і JSON-каталог; `ui` усіх частин — англійські мітки;
стан у `head` стає англійським для моделі, сторінка показує переклад.
Найбільший етап; сторінка після нього виглядає як зараз.

### 4. CLI, майстер, `logs.say`
`memory cli`, `keeper/setup.py`, повідомлення в термінал.

### 5. Застосунок Mac
String Catalog для `apps/mac`.
