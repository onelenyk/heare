# Логи системи: план

Мета: за будь-яку подію можна відповісти «що сталося, де, коли, чому і що
було далі», не заходячи на сервер. Стрічка на пульті лише показує ці дані;
основа тут — самі записи.

## Що вже є

- `heare/logs.py`: один формат рядків, повтори стискаються. Рядки живуть
  окремо на кожній машині, мак не бачить мозку.
- `State.emit`: близько 50 подій мозку. Вони для живої сторінки, не архів.
- Журнал пам'яті: розмова й діяльність, його читає `make digest`.
- Діра: `the stream broke: %s` пише порожню причину, бо текст деяких винятків
  httpx порожній. Причину обривів ми й досі не знаємо.

## Одне правило

Новий шар логування поверх цього не пишемо. Є один запис і один шлях:
`logging` кожного процесу → кільце на диску цього процесу → мозок → сховище.
Код, що вже пише `logger.warning`, лишається; нове місце дописує `log.event`.

## Запис

| Поле | Значення |
|---|---|
| `at` | час із мілісекундами |
| `machine`, `part`, `pid`, `release` | звідки і яка версія |
| `area` | link, turn, stt, tts, model, tool, hands, keys, part, system, http |
| `kind` | що сталося, стабільне англійське ім'я |
| `level` | trace, info, warn, error |
| `trace` | номер репліки чи завдання |
| `span`, `parent` | крок усередині `trace` |
| `ms`, `outcome` | тривалість; ok, failed, refused, timeout |
| `cause` | тип винятку й текст, ніколи не порожній |
| `data` | дрібні поля; лише дозволені для цього `kind` |

Текст для людини не зберігається: сторінка будує його з `kind` через каталог
мов. Тоді і людина, і Claude, і запити читають одні й ті самі дані.

## Що пишемо

| Що | Записи |
|---|---|
| Зв'язок | підключився, обрив з причиною, відновився за N с, перепідключення; помилки TLS і DNS |
| Запити | кожен HTTP до мозку: шлях, статус, мс, хто; без тіла |
| Опитування | успішні лише лічильником за хвилину; кожен збій або зміна стану окремо |
| Репліка | почув, розпізнав, вирішив, виклики, модель, голос, мс кожного кроку |
| Модель | провайдер, модель, токени, ціна, мс, помилка |
| Вміння й руки | виклик, крок, результат, відмова, огорожа, команда, код виходу |
| Ключі | запит, дозвіл, відмова, позика: лише назва ключа й відбиток |
| Частини | старт, падіння, перезапуск, версія; закриття застосунку й причина зміни налаштувань |
| Система | запуск мозку, оновлення, резервна копія, міграції, пам'ять і диск раз на хвилину |
| Винятки | усе, що не перехоплено: повний стек |

Успішний полінг окремим рядком не пишемо: 600 запитів на годину сховали б
справжнє. Лічильник нічого не губить, а збій видно окремо. На потреби є
перемикач рівня `trace` для однієї частини на 30 хвилин.

## Приватність

- Ключі, токени, заголовки авторизації, тіла запитів: ніколи.
- Поля `data` проходять дозволений список, а значення ще й фільтр SECRET.
  Тест кладе в записи ключ-приманку і перевіряє, що його ніде немає.
- Слова людини й відповіді: лише окрема область `speech`, щоб можна було
  дати доступ до журналу без доступу до розмов.

## Доставка й сховище

- Кожен процес спершу пише у свій файл `~/.heare/logs/events-*.jsonl`
  (ротація, до 50 МБ), тому записи переживають обрив, з якого все й почалось.
- Частина надсилає пачки на `POST /api/logs` раз на 5 с або після відновлення
  зв'язку і пам'ятає, де зупинилась. Журнал не блокує голос: черга обмежена,
  а скільки втрачено, пише окремий запис.
- Мозок тримає окремий SQLite з індексами за `at`, `trace`, `area`, `level`,
  окремо від пам'яті. Звичайні 14 днів, помилки 90, ліміт розміру. Резервна
  копія його не бере.
- Годинники машин різні: мозок записує ще й час отримання.

## Читання

- `GET /api/logs?since=&area=&part=&level=&trace=&q=` і живий потік. Той самий
  шлях для пульта й для Claude.
- Вкладка «Журнал»: стан зараз, стрічка, фільтри, шлях репліки, сирий запис,
  «Скопіювати для Claude».
- `make logs`: той самий запит із термінала.
- Доступ Claude: окремий ключ лише для читання, без `speech` за замовчуванням,
  плюс service token Cloudflare, який створює власник.

## Кроки

1. **Причина обриву.** `repr` замість порожнього тексту, час життя потоку.
   Окремий малий випуск: відповідь потрібна вже зараз.
2. **Запис.** Форма, `log.event`, міст із `logging`, фільтр, файл, тести.
3. **Доставка.** Пачки, сховище, зберігання, `/api/logs`.
4. **Покриття.** Зв'язок і частини, далі запити, далі ключі й система.
5. **Шлях репліки.** `trace` через голос, мозок, модель і руки.
6. **Вкладка на пульті**, переклади, `make logs`.
7. **Ключ лише для читання** і доступ Claude.

Кожен крок окремо випускається й перевіряється.

## Тести

- Забороняють порожню причину, запис без `kind`, поле поза дозволеним списком.
- Обрив мозку на 5 хвилин: записи доїжджають, порядок правильний, голос не
  сповільнюється.
- Кожна подія `area` має рядок у каталозі мов.
- Ядро лишається в межах правила імпортів: `log.event` лише зі стандартною
  бібліотекою.

## Вартість

Зміна коду частин: після випусків потрібне нове «Дозволити». Частину записів
з кроку 1 видно лише в журналі мака до кроку 3.
