# Ролі

Роль — це режим поведінки асистента, що вмикається голосовою фразою і накладається
поверх звичайної персони. Роль визначає канал (voice/log), заборонені дії,
тригери входу/виходу та інструкцію для підсумкового артефакту сесії.

Кожна роль — окремий `.md` файл у цій папці: frontmatter + текст поведінки
українською, написаний для голосового відтворення (коротка усна проза, без
markup, без списків у мовленні).

Ключі frontmatter: `name` (канонічна назва), `channel` (`voice` або `log`),
`deny_tools` (опційно), `artifact` (опційно, інструкція для підсумку),
`triggers` (фрази запуску), `end_triggers` (опційно, фрази завершення).

Щоб додати свою роль: скопіюй один з існуючих файлів, зміни `name`,
`triggers`, `artifact` і перепиши тіло під потрібну поведінку — 8-20 рядків,
конкретно про те, що робити на кожному ході розмови.
