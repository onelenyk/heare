heare

панель: налаштування через Bluetooth

З’єднайте панель, введіть код із OLED і збережіть мережу та мозок. Сторінка говорить лише Bluetooth — без точки доступу, без сервера й без токенів.

Chrome / Edge · HTTPS
01

З’єднання

панель не вибрана не підключено

Потрібен Chrome або Edge. Тримайте панель поруч: у списку буде heare-panel-.

02

Код із OLED

Код показується лише на самій панелі. Він не зберігається на сторінці.

03

Wi-Fi

Скан іде через панель. Введена вручну назва має приоритет над списком.

Пароль передається панелі один раз і не пише нікуди, крім самої панелі.

04

Мозок і панель

a–z, 0–9, дефіс.

8 символів від heare-brain code або зі сторінки мозку. Без 0, 1, I, L, O, U.

05

Збереження

Після збереження панель перезавантажиться й сама підключиться до мозку.
