panel: setup over Bluetooth

Connect the panel, enter the code from the OLED and save Wi-Fi. The brain is set later on the panel’s own page — heare-panel.local. This page speaks Bluetooth only: no server and no tokens.

Connection

no panel selected not connected

Chrome or Edge is required. Keep the panel nearby: the list will show heare-panel-.

02

Code from the OLED

The code is shown only on the panel itself. It is not stored on this page.

03

Wi-Fi

The scan runs through the panel. A name typed manually takes priority over the list.

The password is sent to the panel once and is written nowhere but the panel itself.

04

Save

After saving, the panel joins Wi-Fi and shows heare-panel.local on its screen: open that address to set the brain.
