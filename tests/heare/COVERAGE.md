# Нова апка (`heare/`): що перевірено і чим

*12 жовтня 2026.* Рядок — поведінка, яку помітила б людина.

## Три способи перевірки

| Спосіб | Що | Модель | Ціна | Запуск |
|---|---|---|---|---|
| **core** | розмова на підставних частинах: черги, перебивання, доручення, дозвіл | сценарна | 0 | `uv run pytest tests/heare -q` (і в `make test`) |
| **текст наживо** | рядок → справжня модель → рядок | справжня | копійки | `echo "…" \| uv run python -m heare` |
| **слухач** | справжній звук → розпізнавання → модель → синтез → запис виходу → розпізнати назад | справжня | копійки | `uv run python -m heare.listener` |

Слухач той самий для старої апки (`uv run python -m tests.e2e.listen_old`),
тож «не гірше за стару» — це порівняння двох рядків.

Позначки: ✅ покрито · ⏳ ще не написано · 👂 лишається людському вуху.

## Перенесені частини

Тести файлів, перенесених зі старої апки без змін, переписані на нові
шляхи й лежать у `tests/heare/ported/` (нарізка фраз, годинник ходу,
слово-активатор, гасіння луни, рот, речення, розпізнавання, синтез,
модель, правила фраз, «коли», схема бази). Разом із core, API й виконавцями — 561 тест.
